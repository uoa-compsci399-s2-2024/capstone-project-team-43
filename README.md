Short description for our project:
This project is designed to streamline the process of collecting, managing, and allocating capstone projects for CS399. It allows clients to submit project ideas through a project proposal form and to view and edit their previous submissions. Admin are able to review and sort projects, manage semesters and submit their own projects. The students will be able to view and submit their bidding for favoured projects through a project preference form. The system automatically allocates projects based on preferences and other factors, reducing manual work and ensuring a fair distribution process. By having all forms in the same place with a modern user interface, as opposed to several forms which must be shared to applicable users, our system is more straightforward and allows users to access the forms they require without ever having to worry about losing the shared link.
